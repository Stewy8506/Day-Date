# Domain Layer Reference

**Path**: `lib/features/schedule/domain/`

The domain layer is the core of the business logic. It has zero dependencies on Flutter, Riverpod, or Hive. It models entities, operations, and use-case workflows purely in standard Dart.

---

## Entities & Enums

### 1. `time_block.dart`

Represents an allocated interval of time on a given day (1=Monday .. 7=Sunday).

#### `TimeBlockType` (enum)

| Value | Meaning | Description |
|:------|:--------|:------------|
| `fixed` | Rigid commitment | Immovable baseline commitments (classes, work, routine habits, commute). |
| `floating` | Dynamic target allocation | Generated by `PlannerService` to fulfill weekly goals (`TaskTarget`). |
| `deviation` | Schedule override | Blockouts, extensions, or unallocated free time placeholders. |

#### `TimeBlock` (class, extends `Equatable`)

| Field | Type | Description |
|:------|:-----|:------------|
| `id` | `String` | Unique identifier (UUID). |
| `label` | `String` | Human-readable title (e.g., `"Work"`, `"Skill Study"`). |
| `dayOfWeek` | `int` | Weekday integer (1=Monday .. 7=Sunday). |
| `startMinutes` | `int` | Start time as minutes since midnight (0–1439). |
| `endMinutes` | `int` | End time as minutes since midnight (0–1439). |
| `type` | `TimeBlockType` | The category of block. |
| `parentTargetId` | `String?` | For floating blocks, foreign key referencing the associated `TaskTarget.id`. |

**Getters & Methods:**
- `int get durationMinutes => endMinutes - startMinutes`: Calculates the span duration.
- `TimeBlock copyWith({...})`: Immutably clones the object with overridden parameters.

### 2. `task_target.dart`

Represents a weekly goal with allocation constraints (priorities, affinity windows, and daily caps).

#### `TimeAffinity` (enum)

| Value | Preferred Window | Target Hours (Minutes since midnight) |
|:------|:-----------------|:--------------------------------------|
| `morning` | Morning | 06:00 AM – 12:00 PM (`360` – `720`) |
| `afternoon` | Afternoon / Evening | 12:00 PM – 07:00 PM (`720` – `1140`) |
| `lateNight` | Night | 09:30 PM – 11:59 PM (`1290` – `1439`) |
| `flexible` | Any free time | Full day (`360` – `1439`) |

#### `TaskTarget` (class, extends `Equatable`)

| Field | Type | Description |
|:------|:-----|:------------|
| `id` | `String` | Unique identifier (UUID). |
| `name` | `String` | Goal title (e.g., `"Project Development"`). |
| `weeklyHours` | `double` | Total hours targeted per week (e.g. `17.0`). |
| `priority` | `int` | Scheduling priority (1 = highest priority). Lower numbers get first claim on free slots. |
| `affinity` | `TimeAffinity` | Preferred time window during allocation. |
| `dailyCapHours` | `double` | Maximum hours to schedule in a single day (e.g. `3.0h`). |

**Getters:**
- `int get weeklyMinutes => (weeklyHours * 60).round()`
- `int get dailyCapMinutes => (dailyCapHours * 60).round()`

### 3. `schedule_deviation.dart`

Represents user overrides or disruptions applied to the baseline schedule.

#### `DeviationType` (enum)

| Value | Description |
|:------|:------------|
| `blockout` | Blocks out a specific time range (e.g., appointments, outings). Floating targets avoid this slot. |
| `extension` | Extends an existing fixed block (e.g., class runs 2 hours overtime). Shifts following commute buffer. |
| `collegeCancellation` | Cancels recurring fixed commitments for a specific date, re-balancing the schedule according to `OffDayStrategy`. |

#### `OffDayStrategy` (enum)

| Value | Re-balancing Behavior |
|:------|:----------------------|
| `accelerateWeek` | Opens freed hours for floating task targets, fulfilling weekly goals earlier and clearing later days/weekends. |
| `restAndLeisure` | Leaves the freed hours as unallocated leisure/free time, preserving standard schedule on other days. |

#### `ScheduleDeviation` (class, extends `Equatable`)

| Field | Type | Nullable? | Description |
|:------|:-----|:----------|:------------|
| `id` | `String` | No | Unique UUID. |
| `label` | `String` | No | Display name (e.g., `"Doctor Appointment"`, `"Holiday"`). |
| `type` | `DeviationType` | No | Deviation category. |
| `dayOfWeek` | `int` | No | Day of week (1–7). |
| `startMinutes` | `int` | No | Start time in minutes since midnight. |
| `endMinutes` | `int` | No | End time in minutes since midnight. |
| `extendsBlockId` | `String?` | Yes | Target fixed block ID when `type == DeviationType.extension`. |
| `extensionMinutes` | `int` | Yes | Additional minutes to append when `type == DeviationType.extension`. |
| `offDayStrategy` | `OffDayStrategy?` | Yes | Strategy when `type == DeviationType.collegeCancellation`. |
| `date` | `DateTime?` | Yes | Specific calendar date for date-aware cancellations. |

## Repository Interface

**File**: `lib/features/schedule/domain/repositories/schedule_repository.dart`

```dart
abstract class ScheduleRepository {
  Future<List<TimeBlock>> getFixedBlocks();
  Future<List<TaskTarget>> getTaskTargets();
  Future<List<ScheduleDeviation>> getDeviations();
  Future<void> addDeviation(ScheduleDeviation deviation);
  Future<void> removeDeviation(String id);
  Future<void> seedIfEmpty();
  Future<bool> isFirstLaunch();
  Future<void> setCollegeStatusForDate(
    DateTime date, {
    required bool isAttending,
    OffDayStrategy strategy = OffDayStrategy.accelerateWeek,
  });
  Stream<void> watchAllChanges();
}
```

### Method Contract

- `getFixedBlocks()`: Fetches all immutable recurring anchors.
- `getTaskTargets()`: Fetches all active weekly goals.
- `getDeviations()`: Fetches all registered overrides/deviations.
- `addDeviation(deviation)`: Persists a new deviation and triggers reactive recomputation.
- `removeDeviation(id)`: Deletes an existing deviation by ID.
- `seedIfEmpty()`: Populates default fixed routine and floating targets on cold start.
- `isFirstLaunch()`: Checks if database has been seeded.
- `setCollegeStatusForDate(date, isAttending, strategy)`: Toggles attendance on a specific calendar date by adding or removing a `collegeCancellation` deviation.
- `watchAllChanges()`: Returns a broadcast stream that notifies whenever local storage is modified.

## Use Cases

### 1. `SeedInitialData`
- **File**: `seed_initial_data.dart`
- **Purpose**: Checks `isFirstLaunch()` and triggers `seedIfEmpty()` once on first launch.
- **Invocation**: `await SeedInitialData(repository).call();`

### 2. `AddDeviation`
- **File**: `add_deviation.dart`
- **Purpose**: Adds a user deviation into the repository.
- **Invocation**: `await AddDeviation(repository).call(deviation);`

### 3. `GetWeeklySchedule`
- **File**: `get_weekly_schedule.dart`
- **Purpose**: Retrieves all raw fixed blocks, task targets, and deviations, passes them to `PlannerService`, and returns the computed `ScheduleResult`.
- **Invocation**: `final result = await GetWeeklySchedule(repository, plannerService).call();`

## Guide: Adding a New Field to an Entity

1. Update the domain entity constructor, properties, `props`, and `copyWith` method.
2. Update the corresponding Hive Model in `lib/features/schedule/data/models/` with the next `@HiveField(n)` index.
3. Run `dart run build_runner build --delete-conflicting-outputs`.
4. Update `model_mappers.dart` for bidirectional mapping.
5. Update unit tests in `test/`.
